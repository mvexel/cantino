# Cantino

Cantino — an offline OpenStreetMap SDK.

In 1502 Alberto Cantino smuggled a copy of Portugal's secret master map, the
Padrão Real, out of Lisbon. Cantino does the same for your app: a copy of the
master map you carry away. It downloads OpenStreetMap data and an optional
PMTiles basemap for an area your app chooses, keeps it on the device and
queries it with no network.

Android library: `io.github.mvexel:cantino:0.1.0`. See `CHANGELOG.md`.
