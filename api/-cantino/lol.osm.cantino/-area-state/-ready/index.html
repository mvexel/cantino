Ready

data class Ready(val runId: UUID, val area: AreaInfo) : AreaState(source)

Published: OSM data and, if requested, the basemap. Open area's AreaInfo.dataFile with OsmStore.open; already-open stores keep the old snapshot. A cancel that arrives once publishing has begun is ignored and the run still ends here. The import report and snapshot timestamp are in area's AreaInfo.metadata.
