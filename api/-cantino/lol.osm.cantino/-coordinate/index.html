Coordinate

data class Coordinate(val latE7: Int, val lonE7: Int)(source)

A WGS84 point, as returned by OsmStore.wayCoordinates. Like OsmObject.Node, the values are integers in 1e-7 degrees (latE7, lonE7), the storage format, so they compare exactly; lat and lon are the same values in degrees.
