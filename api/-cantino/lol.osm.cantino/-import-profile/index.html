ImportProfile

data class ImportProfile(val keep: List<KeepRule>)(source)

A tag-filtered import: which objects an area keeps.

An object is kept when any rule in keep matches it. References are closed over, as osmium tags-filter does by default: a kept relation keeps all its members (recursively, nested relations included), a kept way keeps all its nodes. Objects kept as references are stored whole, with all tags.

Measured on a 30×15 km Salt Lake City extract (128.5 MB unfiltered): points of interest (amenity, shop, tourism, leisure, craft, office, healthcare, historic) 8.8 MB; routing (highway plus route and restriction relations) 41.4 MB; outdoor 61.6 MB.

An object missing from a filtered area may be filtered out or outside the area; ImportReport.profile says which filter the area was built with.
