PmtilesInfo

data class PmtilesInfo(val minZoom: Int, val maxZoom: Int, val bounds: Bbox, val addressedTiles: Long, val tileEntries: Long, val tileContents: Long, val fileBytes: Long, val specVersion: Int, val centerLon: Double, val centerLat: Double, val centerZoom: Double, val tileType: Int, val tileCompression: Int, val clustered: Boolean)(source)

Header facts of a local PMTiles v3 file, from the Rust validator (cantino_basemap_info). Useful to check a basemap the app ships or downloads itself, or to fit the map camera to bounds.
