Node

class Node : OsmObject(source)

A node. Coordinates are integers in 1e-7 degrees (latE7, lonE7), the storage format, so they compare and round-trip without float drift; lat and lon are the same values in degrees.

locationVersion is the object version at which the node got its current coordinate; it is kept even when metadata is not.

Untagged nodes (the vertices of ways) are stored and returned by OsmStore.get, but they are not spatially indexed: a bbox Query never returns them. Reach them through their ways.
